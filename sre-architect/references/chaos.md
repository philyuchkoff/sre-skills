# Chaos engineering

## Принципы

- Начинай в staging, в прод — только с автоматическим откатом по SLO.
- Перед экспериментом зафиксируй steady state: какие метрики и значения считаются нормой.
- Гипотеза формулируется заранее: «при отказе одной ноды сервис продолжит отвечать с p99 < 300 мс».
- Один эксперимент — одна переменная.
- После каждого эксперимента — разбор и действие, иначе это развлечение.

## Стоп-условия

Эксперимент прерывается автоматически, если:

- SLO нарушен или сгорело больше 2% бюджета;
- деградация длится дольше заданного окна;
- затронуты пользователи вне объявленного blast radius.

Без стоп-условий эксперимент в прод не запускается.

## Уровни

| Уровень | Эксперимент | Критерий успеха | Где |
|---------|-------------|-----------------|-----|
| 1 | удалить один под | нет ошибок, под восстановился | staging |
| 2 | удалить 50% подов | SLO в норме, HPA масштабирует | staging |
| 3 | задержка +100 мс до зависимости | circuit breaker срабатывает, есть деградация | staging |
| 4 | зависимость отвечает 500 | fallback работает | staging |
| 5 | недоступна зона | переключение работает | staging, затем прод |

## Инструменты

| Инструмент | Лицензия | Для чего |
|------------|----------|----------|
| Chaos Mesh | Apache 2.0 | сеть, IO, pod-kill, стресс; богаче по сценариям |
| Litmus Chaos | Apache 2.0 | готовые эксперименты, интеграция с CI |

Оба — self-hosted, в РФ доступны. Версию фиксируй явно, не используй `latest`.

## Примеры

Pod kill (Chaos Mesh):

```yaml
apiVersion: chaos-mesh.org/v1alpha1
kind: PodChaos
metadata:
  name: api-pod-kill
  namespace: staging
spec:
  action: pod-kill
  mode: one
  selector:
    namespaces: [staging]
    labelSelectors:
      app: api
  duration: "1m"
```

Задержка сети:

```yaml
apiVersion: chaos-mesh.org/v1alpha1
kind: NetworkChaos
metadata:
  name: payment-delay
  namespace: staging
spec:
  action: delay
  mode: one
  selector:
    namespaces: [staging]
    labelSelectors:
      app: payment-api
  delay:
    latency: "100ms"
    jitter: "20ms"
  duration: "5m"
```

Отказ зависимости (без Chaos Mesh — обычный mock в staging): подними заглушку, которая отвечает 500 с задержкой, и переключи на неё конфиг.

## Программа внедрения

| Период | Шаг | Критерий готовности |
|--------|-----|---------------------|
| Неделя 1–2 | установить Chaos Mesh в staging, зафиксировать steady state | эксперимент запускается по кнопке |
| Месяц 1 | уровни 1–2, разбор результатов | 2 отчёта, 2 исправления |
| Месяц 2–3 | уровни 3–4 | fallback и breaker проверены |
| Квартал | уровень 5 и автоматизация в CI | chaos-прогон в пайплайне |

## Чего не делать

- Запускать без стоп-условий и без отката.
- Проводить эксперимент, который никто не смотрит.
- Начинать с прода.
- Превращать chaos в самоцель: если сервис без probes и бэкапов — сначала базовые вещи.
