# SLO: [Сервис] — [Название цели]

| Поле | Значение |
|------|----------|
| Сервис | [service-name] |
| Владелец | [команда / oncall] |
| Пользовательский путь | [что важно пользователю] |
| Окно | rolling 28 дней |
| Дата согласования | [YYYY-MM-DD] |
| Пересмотр | [YYYY-MM-DD, квартал] |

## 1. Зачем этот SLO

Одно-два предложения: какой пользовательский эффект защищаем. Пример: «Клиент всегда может оформить заказ: запрос оформления отвечает без ошибок и быстро».

## 2. SLI

| Поле | Значение |
|------|----------|
| Тип | availability / latency / freshness / correctness |
| Источник | Prometheus / VictoriaMetrics |
| Числитель | `sum(rate(http_requests_total{status!~"5..", route!~"/health|/metrics"}[5m]))` |
| Знаменатель | `sum(rate(http_requests_total{route!~"/health|/metrics"}[5m]))` |
| Окно | 5 минут (расчёт), 28 дней (SLO) |

## 3. Цель

| SLI | Target | Почему именно так |
|-----|--------|-------------------|
| Availability | 99.9% | текущий уровень 99.92%, цель с запасом |
| Latency (доля < 300 мс) | 99% | ожидание пользователя на оформление |

## 4. Error budget

- Бюджет: **40 минут за 28 дней** при 99.9%.
- Текущий остаток: ссылка на дашборд.

## 5. Политика бюджета

| Остаток | Что происходит |
|---------|----------------|
| > 50% | обычный режим |
| 25–50% | релизы с усиленным ревью и планом отката |
| 0–25% | только исправления надёжности |
| 0% | заморозка фич до восстановления бюджета |

## 6. Алерты

| Severity | Burn rate | Окна | Канал |
|----------|-----------|------|-------|
| P0 | 14.4 | 1h + 5m | Telegram + звонок |
| P1 | 6 | 6h + 30m | Telegram |
| P2 | 1 | 3d + 6h | тикет |

Правила и запросы — `references/burn-rate.md`.

## 7. Исключения

- `/health`, `/ready`, `/metrics` — служебные эндпоинты.
- Трафик нагрузочных тестов: метка `load_test="true"`.
- Внутренние вызовы: `client="internal"`.

Исключение без метки в метриках не работает — метка должна быть в коде.

## 8. Что считается успехом и ошибкой

**Успех:** запрос вернул 2xx/3xx и уложился в порог задержки.
**Ошибка:** 5xx, таймаут, обрыв соединения.
**Не считается:** служебные эндпоинты, нагрузочные тесты, боты с известными User-Agent.
